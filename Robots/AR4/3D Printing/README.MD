The Bambu.3mf file can be opened with [Bambu Studio](https://bambulab.com/en-us/download/studio) for use with a Bambu printer.  

Most all files in this are from Chris Annin's [downloads page](https://anninrobotics.com/downloads/) and are provided as an 'as-built' for the AR4 Mk3 robot that was used in the development of ArfBotOS.  

Additionally, there are some custom files - for example the ArfBotOS wedge - that will be needed if you intend to use ArfBotOS with your AR4 Mk3 arm.  

The grippers used are designed by Skip Baker and can be downloaded at his [GrabCAD](https://grabcad.com/library/ar4-robot-pneumatic-gripper-assembly-1) link.
